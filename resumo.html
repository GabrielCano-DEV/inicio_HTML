Segue o passo a passo

PRIMEIRO PASSO

Crie um repositório no GitHub: Abra o github, vá até o new repository, e preencha as inforamções como preferir.

SEGUNDO PASSO

Crie uma pasta em seu computador e abra ela no VS CODE, após isso, digite o comando "git init" no terminal

TERCEIRO PASSO

Criar um arquivo MARKDOWN (md) chamado "README.md"

QUARTO PASSO

Digite o comando "git add README.md" e depois adicione uma mensagem para registrar as alterações.

use o comando "git push -u origin main", para que o documento seja direcionado para a branch principal.

QUINTO PASSO

Agora você ja pode criar o seu documento ".html" e colocar nele as informações que desejar
